Parametric Tests Using Python

1. Introduction

Parametric tests are statistical methods used to analyze sample data and make conclusions about population parameters. These tests generally assume that the data follows a normal distribution.

This project demonstrates different parametric and non-parametric statistical tests using Python.

2. Objectives

- To understand parametric statistical tests.
- To perform one-sample and two-sample tests.
- To understand one-tail and two-tail tests.
- To check data normality using the Shapiro-Wilk test.
- To compare parametric and non-parametric methods.
- To implement statistical tests using Python.
